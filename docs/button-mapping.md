# Button Mapping

## Physical Layout

| Location | Buttons |
|----------|---------|
| Bottom edge | BACK, CONFIRM, LEFT, RIGHT |
| Right side | UP, DOWN |
| Right side (separated) | POWER |

## Short Press

| Button | Home | Reader | Passes | Settings | Jump Page |
|--------|------|--------|--------|----------|-----------|
| BACK | — | → Home | → Home | → Home | Cancel |
| CONFIRM | Select item | — | — | Toggle/Confirm | Jump |
| LEFT | — | Prev page | — | — | — |
| RIGHT | — | Next page | — | — | — |
| UP | Menu up | Prev page | Prev pass | Menu up | +1 page |
| DOWN | Menu down | Next page | Next pass | Menu down | -1 page |
| POWER | Sleep | Sleep | Sleep | Sleep | Sleep |

## Long Press

| Button | Any screen | Notes |
|--------|-----------|-------|
| BACK | → Settings | Quick access settings from anywhere |
| CONFIRM | → Jump to page | Only in Reader mode |
| POWER | → Passes view | Quick access passes from anywhere |
| UP | — | +10 pages in Jump dialog |
| DOWN | — | -10 pages in Jump dialog |

## Notes

- Button mapping may change based on user testing with MVP
- UP/DOWN and LEFT/RIGHT may share function depending on context
- Portrait vs landscape mode may affect mapping
- Allow swap UP/DOWN direction when reading for ergonomics
- Long press threshold: ~500ms
- Emulator supports long press via mousedown duration or keyboard hold
